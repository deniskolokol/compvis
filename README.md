# compvis
Computer Vision utils

## About the Project
`compvis` is an educational project aimed at learning computer vision technologies.

## Key Components

- **commands/**: all executable commands.
  
- **utils/**: utilities housed in this directory serve various auxiliary functions that support the main operations.
  
- **media/**: content for commands: images, videos, and other multimedia formats.
